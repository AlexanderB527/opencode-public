# Режим: deep (уровень 3 — точечный разбор причины)

> Часть скилла `testops-rerun-triage`. Общие правила — `../SKILL.md`.
> Статус: **спроектирован, реализация — следующий шаг.** Ниже контракт режима.

## Назначение

Уровень 2 отвечает «кто виноват и что группируется». Уровень 3 отвечает на другой вопрос:
**почему конкретный кластер не работает и что делать**. Запускается точечно — по кластеру
или по номерам, а не по всему прогону.

## Вход

- `rerun_id` + кластер (`rule_key`/`subgroup`) или явные номера тестов.
- Данные уровня 2 берутся из `triage_classification.json`: `own_frame`, `gem_frame`, `locator`, `message`.

## Источники (только на этом уровне)

| Источник | Что даёт | Как |
|---|---|---|
| TestOps | определение и шаги тест-кейса, предусловие, теги | `/api/testcase/{id}`, `/api/testcase/{id}/step` |
| git `AUTOTEST/sfa` | локус `файл:строка`, история правки лока | grep по локатору/номеру, blame |
| Confluence | известные дефекты и прошлые разборы | поиск по номеру теста и тексту ошибки |

Скилл ходит в эти источники **сам**, но только в этом режиме: для `classify` они не нужны
и не запрашиваются.

## Выход

`~/.qa-artifacts/triage/{rerun_id}/deep/{key}.json` + блок в чат:

```
@{представитель} — {название} (+ N тестов: @.. @..)
Тип: {система|автотест|дефект}
Ошибка: {message}
Стек: {own_frame} -> {gem_frame}
Шаги: {упавший шаг тест-кейса, если найден}
Причина: {вердикт + чем подкреплён}
Confidence: {high|medium|low} (score {N}: {evidence})
Решение: {что конкретно менять/проверить}
Routing: {кому} · {приоритет} · {критерий готовности}
```

## Правила режима

1. **Глубина — на представителя кластера**, остальные номера ссылаются на вердикт.
2. **Git-проверка обязательна для автотестов**: локатор есть в коде → элемент не прогрузился
   (окружение); локатора нет/устарел → чинить тест. Без git вывод — «не подтверждено».
3. **Для системы** ищется не тест, а сервис: какой вызов вернул SOAP Fault, есть ли известный
   дефект стенда в Confluence.
4. **Не выдавать причину без evidence**; «не подтверждено» — валидный результат.
5. **Не менять код и не заводить дефекты** — только предлагать.

## Открытые вопросы к реализации

- Резолв «номер теста → файл feature/step definition» в `AUTOTEST/sfa` (эвристика по номеру + названию).
- Доступ к Confluence: MCP `atlassian` (в скилле не зашит; режим сообщает, если недоступен).
- Формат `deep/{key}.json` зафиксировать до первой реализации, чтобы не менять контракт.
