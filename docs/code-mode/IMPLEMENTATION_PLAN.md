# План и статус реализации MVP

ADR и список файлов согласованы. Реализованы V2-инструменты и адаптеры. Проверка изолированного native execute, smoke рабочего Desktop/GUI и замеры на провайдере требуют целевого окружения.

1. Проверить целевой Desktop/server, V2 регистрацию, разрешения вложенных вызовов, сигнал и поля usage. На тестовом профиле включить native execute только при соблюдении ADR. Утвердить fixture на основной запуск и реран с ожидаемыми каноническими результатами.
2. Добавить типы и реестр, валидаторы и исполнитель. Проверить неизвестные операции, повторный вызов, ограничения пула и прекращение зависимых стадий при отмене. Начальные лимиты для калибровки — две активные операции на workflow, 20 записей evidence и 16 КиБ модельного ответа. HTTP/Python бюджеты подбираются на репрезентативных fixtures, превышение никогда не выдаётся как полный результат.
3. Подключить JS brief и Python triage. Провести сигнал до HTTPS и фиксированного Python-процесса. Сначала интеграционный тест с имитацией API, затем сравнение канонической классификации и полноты с CLI. Дополнительный evidence выдавать по сессионному снимку с ограниченным временем жизни. При повторном запросе проверять permission заново.
4. Зарегистрировать входы в серверном плагине под feature flag. Проверить основной и triage маршруты, выключенный флаг и несовместимый runtime. Состояние, RPC GUI, Jenkins и публикация остаются на существующем пути. Сокращение GUI-промпта рассматривать отдельно после доказанного паритета маршрутизации.
5. Добавить обезличенные метрики, выполнить benchmark и обновить README. Метрики содержат маршрут, статус, длительность, количество запросов и объём проекции. Токены брать из данных OpenCode по границам тестового задания, отсутствующий usage отмечать как неизвестный.

## Проверки перед включением

- Golden сравнение нормализованных результатов при одинаковых входах, включая параметризацию, skipped, фильтры команды и тега, эталон и low confidence. В канонических схемах нет изменений.
- Частичная пагинация и отсутствие trace, 401, 429, сбой транспортного уровня и таймаут VPN, отмена HTTP и Python, ограничения объёма и параллелизма.
- Permission deny до I/O, отклонение внешних путей и URL, лишних аргументов и чужого идентификатора evidence. Guard smoke test на штатном хосте и проверка отсутствия записей.
- Существующие Node и Python тесты, smoke GUI/RPC с отключённым и включённым флагом, сравнение токенов, шагов и времени на одинаковом сценарии.
